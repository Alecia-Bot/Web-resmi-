SEWA BOT 15 HARI

Bot disewakan khusus untuk dimasukkan ke dalam grup WhatsApp. Cocok untuk meramaikan grup, membantu admin, dan menyediakan berbagai fitur hiburan serta utilitas otomatis.

Harga paket Rp 6.000 Aktif 15 hari

Fitur Bot Group

  • Game seru (tebak gambar, quiz, dll)
  • Fun command & hiburan
  • Auto welcome & goodbye member
  • Anti link / anti spam
  • Anti toxic / kata kasar
  • Tag semua / hidetag
  • Sticker & converter media
  • Downloader (TikTok, IG, dll)
  • Random anime / quotes / dll
  • Leveling & rank member
  • AFK system
  • Vote & polling grup

Fungsi Admin

  • Kick / add member (jika bot admin)
  • Close / open grup
  • Reset link grup
  • Promote / demote
  • Anti link grup lain
  • Anti virtex / anti bug

Cocok Untuk

  • Grup komunitas
  • Grup tongkrongan
  • Grup publik / open member
  • Grup roleplay / game
  • Grup jual beli biar rame

Ketentuan Sewa

  • Bot dimasukkan ke grup Anda
  • Durasi sesuai paket sewa
  • Owner grup bebas menggunakan fitur bot
  • Bot online 24 jam (selama server normal)
  • Tidak untuk spam / bug grup lain
  • Bot siap meramaikan grup + membantu admin otomatis
